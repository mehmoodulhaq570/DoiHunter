# Security Policy

## Supported versions

Security updates are provided for the latest release.

| Version | Supported |
| --- | --- |
| 1.2.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/mehmoodulhaq570/DoiHunter/security/advisories/new).
Do not disclose an unpatched vulnerability in a public issue.

Include reproduction steps, affected versions, potential impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.
